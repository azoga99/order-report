# Отчёт по заказам

Консольное приложение на Java: формирует отчёт по списку заказов — сортирует их по убыванию суммы,
рассчитывает комиссию платёжной системы для каждого заказа и выводит итоговую сумму комиссий.

Ставка комиссии зависит от способа оплаты:

| Способ оплаты              | Ставка |
|----------------------------|--------|
| Карта российского банка    | 1.5 %  |
| Карта зарубежного банка    | 3.5 %  |
| СБП                        | 0.4 %  |
| Наличные                   | 0 %    |

## Структура проекта

```
src/main/java/org/hse/examples/
  App.java                     точка входа, демонстрационный сценарий
  Order.java                   заказ (record с валидацией суммы)
  Payment.java                 способ оплаты (sealed interface: Card, Sbp, Cash)
  CommissionPolicy.java        правило расчёта комиссии
  RateCommissionPolicy.java    комиссия по фиксированным ставкам
  OrderReportService.java      сортировка заказов и суммирование комиссий
  OrderFormatter.java          форматирование строк отчёта
src/test/java/org/hse/examples/  модульные и интеграционный тесты (JUnit 5)
```

## Требования

- JDK 21
- Apache Maven 3.9 и новее

## Сборка

```bash
mvn clean package
```

Собранный JAR появится в `target/lesson4-1.0-SNAPSHOT.jar`.

## Запуск

```bash
java -cp target/classes org.hse.examples.App
```

## Тесты

```bash
mvn test
```

Тесты написаны на JUnit 5 и покрывают расчёт ставок, сортировку и агрегацию заказов,
форматирование вывода, валидацию суммы и граничные случаи (нулевая сумма, пустой список).

## Плагин JaCoCo

В сборку подключён `jacoco-maven-plugin` — он измеряет покрытие кода тестами.
Плагин настроен на три шага:

- `prepare-agent` — подключает агент, который во время прогона тестов собирает данные о выполненных строках;
- `report` — по завершении фазы `test` формирует отчёт в `target/site/jacoco` (HTML, XML, CSV);
- `check` — на фазе `verify` проверяет, что покрытие по строкам не ниже 80 %, и иначе прерывает сборку.

Полный прогон с проверкой покрытия:

```bash
mvn clean verify
```

Отчёт открывается в браузере: `target/site/jacoco/index.html`.
Текущее покрытие — 97 % строк и 100 % ветвлений.

## Ветки

- `main` — стабильное состояние проекта;
- `develop` — ветка разработки, в неё вносятся изменения перед слиянием в `main`.
